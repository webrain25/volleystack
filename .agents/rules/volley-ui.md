# UI/UX Project Rules

- Preservare tutte le funzionalità esistenti.
- Non cambiare business logic, database, API o autenticazione durante attività puramente grafiche.
- Utilizzare i design token esistenti, estendendoli se necessario.
- Non introdurre librerie senza una motivazione tecnica.
- Produrre modifiche piccole e verificabili.
- Prima di modifiche estese, proporre un piano.
- Testare i principali flussi dopo ogni intervento.
- Utilizzare le skill UI/UX installate quando pertinenti.
